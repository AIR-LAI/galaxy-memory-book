# 给你的星河回忆册

这是一个给女朋友的银河回忆书小网站。它是静态网页，不需要安装依赖，也不需要构建。

## 打开网站

直接双击 `index.html`，或在浏览器里打开它。

## 替换照片

把你们的照片放进 `photos/` 文件夹，然后按 `data/memories.js` 里的文件名替换。

例如第一页默认使用：

```text
photos/page-01-1.jpg
photos/page-01-2.jpg
```

你可以把自己的照片改名成这些名字，也可以在 `data/memories.js` 里改成你自己的文件名。

如果某张照片还没放进去，网页会显示星光占位，不会影响翻页。

## 修改文字

所有标题、每页短句和照片路径都在 `data/memories.js`。

每一页长这样：

```js
{
  kicker: "Chapter 01",
  title: "我们故事的第一页",
  text: "从那天开始，很多普通的日子，都慢慢有了光。",
  photos: ["photos/page-01-1.jpg", "photos/page-01-2.jpg"]
}
```

改 `title` 和 `text` 就能换成你想对她说的话。

## 建议

手机上看会更有惊喜感。可以先把照片换好，再把整个文件夹上传到静态网站托管服务，或者之后让我继续帮你发布成一个链接。
